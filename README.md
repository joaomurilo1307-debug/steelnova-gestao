# SteelNova Gestão

Sistema interno de gestão de obras da SteelNova Engenharia: planejamento, kanban, gantt, RDO, custos, equipe, relatórios e matriz RACI. PWA instalável, acessível por navegador (celular ou PC), sem depender do Claude.

Stack: Next.js 14 (App Router) + TypeScript + Tailwind + Prisma/PostgreSQL + NextAuth.
